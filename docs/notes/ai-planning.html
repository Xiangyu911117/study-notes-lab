核心概念

在這份筆記裡，Planning 指先形成工作安排，再依安排逐步處理任務。只列出『閱讀、整理、報告』還不是完成工作；每一步都需要對應的輸入與成果。

模型呼叫之間不會因為程式寫在同一個檔案就自動共享成果。若第二步需要第一步的摘要，程式必須將摘要帶入下一次請求。

這是一種教學用的規劃與執行流程。不同文件對 Agent 的定義不同；固定的執行流程也可稱為 workflow，不代表系統已具備完全自主能力。

操作步驟

  1. 先寫清楚目標、提供材料，以及不能自行猜測的限制。
  2. 請 AI 列出子任務，為每一步指定成果和前置條件。
  3. 檢查順序是否合理，再執行第一步，把結果傳入後續步驟。
  4. 最後對照原始目標核對結果；某一步失敗時保留已有內容，避免把空白結果繼續傳下去。

具體例子

示例：準備一份課堂報告。 第一步：從已提供的要求整理必備項目。 第二步：使用必備項目產生報告提綱。 第三步：依提綱列出尚缺材料與準備待辦。 若沒有提供論文，第三步可以列出要找的資料，不能假裝已閱讀論文並填入研究結果。

易錯提醒

  • 把 AI 顯示『完成』誤認為真實世界的報告已經繳交。
  • 只檢查 JSON 格式，卻沒有查證內容是否正確。
  • 後一步忘記傳入前一步結果，導致各步互相矛盾。
