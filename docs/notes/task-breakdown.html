把大作業拆成可以開始的小步驟

用可交付的成果描述任務，讓待辦清單不再只有『讀書』和『做報告』。

核心概念

這篇提供一套自訂的作業整理流程，不是經實驗驗證的效率公式。核心做法是為每個任務寫出一份看得見的成果，例如『列出三個待查問題』，比『認真讀論文』更容易判斷下一步。

時間只是規劃用的估計，完成一個勾選項目也不等於已經理解全部內容。遇到讀不懂的地方，可以另外記錄問題，而不是為了勾選完成而跳過。

操作步驟

  1. 先記錄老師要求的交付內容與截止時間，不自行補出不存在的規定。
  2. 依交付內容拆出子任務，每一項用動詞加上成果，例如『整理一頁方法比較』。
  3. 把有前後關係的項目排好，先有材料，再整理內容，最後檢查格式。
  4. 估計每項所需時間並對照可用時段；排不下就調整工作範圍或拆得更細。

具體例子

示例：『做報告』可改成四項待辦。 1. 整理老師要求與評分重點。 2. 列出四頁提綱及每頁的一句重點。 3. 為每頁補上可追溯的資料或圖片。 4. 計時試講並記錄需要刪減的地方。 以上是規劃示例，不代表任何人的實際作業已完成。

易錯提醒

  • 把『找資料』寫成唯一一項，沒有說明要找什麼或找多少。
  • 只看截止日，不考慮前置工作尚未完成。
  • 把預估時間當成保證，沒有保留修正安排的空間。
